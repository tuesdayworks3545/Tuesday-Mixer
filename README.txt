TUESDAY MIXER
=============

Created and published by Tuesday Works.

Open "Tuesday Mixer.exe" to start the app. Keep tuesday.ico and tuesday.png in
the same folder so the supplied Tuesday branding appears in the window.

Features
--------
- Controls the main Windows output volume and mute state.
- Controls each currently running audio app separately.
- Remains synchronized with the Windows audio system.
- Combines multiple audio streams belonging to the same application.
- Uses Tuesday's colors, typography, cards, controls, and Mixer icon.
- Uses a fully dark title bar and dark scroll styling.
- Shows live left and right audio meters for the master output and every app.
- Refreshes meters at 30 FPS with fast-attack, smooth-release animation.
- Drag the handle at the upper-right of an app card to rearrange channels. The
  chosen order is remembered between launches.
- Click the pencil beside any app—or double-click its name—to assign a custom
  channel name. Custom names are remembered between launches.
- Uses a standard resizable Windows frame, including Windows Snap layouts and
  one-third-screen positioning provided by Windows.
- No installation or administrator access is required.
